# ☕ Кофеин

**Сколько кофеина сейчас в крови и когда получится уснуть.**

### ▶️ [Открыть](https://mysik-portfolio.vercel.app/caffeine/)

Работает на телефоне и на ПК, без установки и регистрации.

## Возможности

- Модель всасывания и выведения с периодом полувыведения
- График на сутки вперёд на SVG
- Время, когда кофеин упадёт ниже 50 мг
- Дневная норма 400 мг и журнал напитков

## Стек

JavaScript, SVG. Один файл `index.html`, без фреймворков и сборки.

## Запуск локально

```bash
git clone https://github.com/mmmaksmog-commits/caffeine.git
cd caffeine
python3 -m http.server 8000
```
